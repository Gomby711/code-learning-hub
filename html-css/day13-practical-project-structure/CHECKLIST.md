# Day 13 Checklist

- [ ] Your reorganized project has `index.html` at the root, a `css/` folder containing your stylesheet, and (if applicable) an `images/` folder
- [ ] Opening `index.html` directly in a browser still shows a fully, correctly-styled page (proving your relative paths were updated correctly after moving files)
- [ ] If you have git: `git log --oneline` shows at least 2 separate, clearly-described commits
- [ ] If you have a GitHub account: you can visit your own live `https://your-username.github.io/your-repo-name/` URL from a browser and see your actual site rendered
- [ ] You can explain, in your own words, why `index.html` specifically is the filename browsers/servers look for by default
