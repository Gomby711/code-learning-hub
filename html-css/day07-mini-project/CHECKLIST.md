# Day 7 Checklist

- [ ] The page has exactly one `<h1>` and uses `<header>`, `<nav>`, `<main>`, `<section>` (or `<article>` where appropriate), and `<footer>` — not an unbroken wall of `<div>`s
- [ ] The header's logo and nav links are arranged with Flexbox, and stay pinned to opposite edges as you resize the window
- [ ] The hero section's content is centered both horizontally and vertically using Flexbox
- [ ] The projects section shows at least 3 cards arranged in a CSS Grid, using `repeat()` and `fr` so they share width evenly
- [ ] The about section reads as a coherent paragraph or two, not placeholder text
- [ ] The contact form has name, email, and message fields, each properly connected to a `<label>` (click each label's text and confirm focus jumps to its input)
- [ ] The footer has a copyright line
- [ ] `box-sizing: border-box` is the first rule in your stylesheet
- [ ] Open DevTools and spot-check at least one element where you were unsure which CSS rule would win — confirm your prediction using the Styles panel
- [ ] The whole page reads as one coherent design, not several disconnected sections with inconsistent spacing

Compare against `solution/` once you've made a genuine attempt.
