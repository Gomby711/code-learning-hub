# Day 2 Checklist

Open your edited `starter.html` in a browser and confirm:

- [ ] A header area at the top shows a site name and 3 navigation links
- [ ] A "Contact Us" form is visible with: name field, email field, message textarea, a dropdown, and a submit button
- [ ] Clicking directly on each `<label>`'s TEXT moves the cursor into its matching input (proves `for`/`id` are correctly matched) — try this for at least 2 of your labels
- [ ] The email field, when you try typing something without an `@` and pressing submit/tab away, behaves differently than a plain text field would (some browsers show a validation hint) — just observe this, you'll learn to control it fully on Day 12
- [ ] A "Pricing" table is visible with a bold/centered header row and at least 2 data rows underneath
- [ ] Right-click the table → Inspect → confirm you used `<thead>`, `<tbody>`, `<th>`, and `<td>` correctly (not all `<td>`)
- [ ] A footer with a copyright line appears at the very bottom of the page
- [ ] View source (Ctrl+U) and confirm you used `<header>`, `<nav>`, `<main>`, and `<footer>` — not generic `<div>`s — for these regions

Compare against `solution.html` if anything is unclear.
