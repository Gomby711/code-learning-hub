# Day 0 Checklist

Open `starter.html` (or your edited version) in a browser and confirm:

- [ ] The browser tab shows the title "Day 0 Practice" (from the `<title>` tag)
- [ ] An `<h1>` heading reading "My First Page" is visible on the page, displayed large and bold by the browser's default styling
- [ ] A paragraph introducing yourself is visible below the heading
- [ ] You added at least one HTML comment (`<!-- ... -->`) somewhere in the file, and confirmed it does NOT appear anywhere on the visible page
- [ ] You opened DevTools (F12), clicked the **Elements** tab, and clicked your `<h1>` in the page — confirming the matching `<h1>` line highlights in the DevTools panel
- [ ] You tried editing the heading's text directly inside DevTools' Elements panel, saw it change live on the page, then reloaded the page (F5) and confirmed the change disappeared (proving DevTools edits are temporary, not saved to your file)

Compare your result to `solution.html` if anything is unclear.
