# Career & Beyond — From "I Can Code" to "I Get Paid To Code"

**Goal:** everything the Python / JavaScript-TypeScript / HTML-CSS tracks deliberately leave out because it isn't
"the language" — but is exactly what turns finished lessons into an actual job. This track assumes you've
already gone through (or are going through) at least one of the other three courses; it doesn't re-teach syntax.

**Why this exists:** knowing a language and being employable as a developer are two different skills. The other
three tracks build the first one extremely thoroughly. This one builds the second: the tools, workflows, and
knowledge that show up in *every* job regardless of language — version control, algorithmic interviews, shipping
a real project publicly, and understanding how the pieces of a modern web/app stack (frontend framework, styling,
backend, database, hosting) fit together.

## How this folder works

Same format as the other tracks: `lesson.md` per day, `exercises.py`/`exercises.js` with `# TODO`/`// TODO`
blanks where the topic is genuinely code-gradable, `solutions.*` to check against. Some days (Git, deployment,
job search) are deliberately reading-and-doing rather than "write a function," because that's the honest shape
of those skills — you'll be told exactly what to *do* instead.

## A note on honesty

No course — this one included — makes you job-ready by itself. What actually gets someone hired: knowing a
language well (the other 3 tracks), being able to build something real without a lesson holding your hand
(Day 4 here), being able to talk through your reasoning on an algorithm problem out loud (Days 2-3), and having
2-4 finished, deployed, linked projects a stranger can actually open (Day 7). This track is the map; you still
have to walk it — mostly by building things this course doesn't tell you how to build, using things it does.
